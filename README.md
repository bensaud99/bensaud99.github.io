# منصة أبو سعود لتطبيقات وأدوات iOS ومستودع السورس (Portfolio & Repo)

موقع وتطبيق ويب متكامل ثنائي اللغة (عربي / إنجليزي) بالمظهرين الداكن والفاتح، يدمج بين عرض التحميلات المباشرة (TrollStore IPA) وسورس جيلبريك رسمي لـ Sileo و Zebra مؤتمت بالكامل عبر GitHub Actions.

## التشغيل السريع محلياً:
```bash
python3 -m http.server 8080
```
ثم افتح متصفح سفاري على الرابط: `http://localhost:8080`
